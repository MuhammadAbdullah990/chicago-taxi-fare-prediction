# Chicago Taxi Fare Prediction 🚕

## 📌 Objective
Predict taxi fare using trip data such as distance, duration, location, and trip attributes.

## 🧠 Workflow
- Data Cleaning
- Feature Engineering
- Encoding categorical variables
- Model Training (Linear Regression, Random Forest)
- Model Evaluation (MAE, RMSE)

## 📊 Key Insights
- Trip distance is the strongest predictor of fare
- Trip duration significantly impacts fare
- Random Forest performs better than Linear Regression

## 🛠 Tech Stack
Python, Pandas, Scikit-learn, Matplotlib, Seaborn

## 📈 Models Used
- Linear Regression
- Random Forest Regressor
